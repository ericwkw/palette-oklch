Ramps

Every ramp shares the same lightness steps, so a shade means the same weight whatever the hue. Chroma peaks near the middle and eases off at both ends. Click any swatch to copy its value.

Dark mode

Same hues, same step order: 50 stays the lightest. The curve lifts the deep end and eases the light end, so dark surfaces stay separable.

Roles & tokens

Roles name what a colour is for; tokens are what a product uses. Ramp steps are the primitives underneath, so a palette swap never changes a token name.

Contrast

WCAG 2 ratios with APCA alongside. WCAG needs 4.5 for body text and 3.0 for large text or UI edges; APCA Lc 60 is roughly body text, Lc 45 large text.

Token pairs

Every pair the tokens actually put together, at the level each one needs: 4.5 for text, 3.0 for edges and marks.

Opacity & overlays

A colour at an alpha over a known background composites to an exact solid — shown here so a tint can be matched back to a real ramp step. Over photographs there is no single background, so drop an image in and the worst case is measured from its own pixels.

Alpha over surfaces

Scrims over an image

No image loaded uses a light-and-dark test pattern. With an image, drag the box to where the caption will really sit — the pixels inside it are measured by percentile, so one glint of sunlight does not decide the scrim for the whole picture.

Gradients

Interpolated in OKLCH, so a blend between two hues keeps its chroma instead of passing through grey. Copy the CSS under each.

Brand family

One parent and its sisters. A sister sets its own main hue and colourfulness — it may travel a long way — and takes everything else from the parent: the same neutrals, the same six functional colours, the same lightness steps, ramp shape and token mapping. That is what makes them read as one family.
